Windows Server & Active Directory Lab

Project Overview

This project documents my hands-on practice with Windows Server administration and Active Directory.

The objective is to build a small enterprise-style Windows environment and practice common tasks performed by IT Support Specialists and System Administrators.

Objectives

* Install and configure Windows Server
* Configure Active Directory Domain Services (AD DS)
* Create a Windows domain
* Create Organizational Units (OUs)
* Create users and security groups
* Configure Group Policy
* Configure DNS
* Join a Windows client computer to the domain
* Configure user permissions
* Troubleshoot common Active Directory issues
* Document the entire process
